# Antigravity Rules for @isthis/agentic

이 프로젝트의 모든 개발 규약 및 TDD 검증 명령은 프로젝트 루트의 `AGENTS.md`를 **단일 진실 공급원(SSOT)**으로 준수한다.

## 필수 지침
1. 작업 시작 시 항상 루트의 `AGENTS.md`를 읽고 프로젝트의 TDD 원칙과 검증 명령을 숙지하라.
2. 코드 수정 전 실패하는 테스트(Red)를 먼저 작성하고 최소한의 코드로 통과(Green)시켜라.
3. 코드 수정 후 반드시 `npm run check`를 직접 실행하여 exitCode 0 기계 증거를 확인하라.
4. 프로젝트 도메인 규칙 및 확장은 오직 `AGENTS.md`를 단일 정본으로 따른다.
