# Antigravity Rules for @isthis/agentic

이 프로젝트는 Antigravity 에이전트와 페어 프로그래밍으로 개발됩니다.

## 필수 가이드라인

1. **결정론적 검증:** 코드 변경 후 `npm run check`를 직접 터미널에서 실행하여 테스트 통과를 확인하세요. 테스트 0개는 실패입니다.
2. **Red-Green-Refactor TDD:** 구현 전에 반드시 실패하는 테스트(Red)를 먼저 작성하고, 최소한의 코드로 통과(Green)시킨 뒤 정리(Refactor)하세요.
3. **서브에이전트 위임:** 조사 및 배경 작업은 서브에이전트를 활용하여 메인 컨텍스트를 깔끔하게 유지하세요.
4. **규칙 승격:** 작업 중 유용한 범용 패턴을 발견하면, 서브에이전트를 통해 `agentic` Core 저장소의 규칙에 순수 기술 패턴만 반영하세요.
5. **비밀값 및 파괴적 명령 금지:** `.env` 내용 노출 및 승인 없는 강제 푸시를 금지합니다.
