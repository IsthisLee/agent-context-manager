# 0001. 지침 생성·설정·동기화·적용 패키지로의 제품 범위 확정

* **상태:** 채택됨 (Accepted)
* **일자:** 2026-09-13
* **결정자:** 제품 소유자·개발자
* **관련:** [0003](0003-rename-core-to-guidance-profile.md)이 이 결정의 "Core" 용어를 Guidance Profile로 대체한다.

## 배경

기존 문서는 하네스 런타임, 검증 도구, 가상 팀, 적응형 역할, Core 관리가 모두 핵심 기능인 것처럼 설명했다. 이로 인해 Agentic이 실제로 무엇을 제공하는지와 향후 확장 영역이 섞였다.

## 검토한 대안

1. 자체 런타임과 멀티 에이전트 오케스트레이션까지 핵심 제품으로 유지한다.
2. 테스트·평가 도구를 중심 제품으로 유지한다.
3. 여러 에이전트가 같은 프로젝트 지침을 사용하도록 지침을 생성·설정·동기화·적용하는 패키지로 범위를 확정한다.

## 결정

Agentic의 핵심 제품은 다음으로 확정한다.

> Agentic은 개인·조직별 에이전틱 개발 지침을 Core로 생성·설정하고, 이를 로컬 또는 Git 기반으로 관리하며 프로젝트와 여러 AI 에이전트에 안전하게 적용·동기화하는 패키지다.

Core는 용도별 공통 지침 저장소이며, 프로젝트 도메인 지침은 대상 프로젝트가 소유한다. 자체 에이전트 런타임, 모델 호출, 인증, 세션, 가상 팀 오케스트레이션은 핵심 범위에서 제외한다.

Core의 로컬 관리가 현재 범위다. 조직 Core의 Git 기반 공유·갱신은 이 제품 범위와 양립하지만, 별도 설계·안전 계약·구현 완료 전에는 제공 기능으로 간주하지 않는다.

## 결과 및 영향

Core 생성·setup·프로젝트 적용·에이전트별 산출물 동기화를 우선 구현한다. 기존 검증·TDD·하네스 관련 기능은 Core에 선택 가능한 지침으로 재배치하며, 독립적인 평가 시스템이나 런타임 기능으로 확장하지 않는다.
