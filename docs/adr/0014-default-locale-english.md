# 0014. 패키지 기본 로케일을 영어로 바꾼다

* **상태:** 채택됨 (Accepted)
* **일자:** 2026-09-15
* **결정자:** 제품 소유자
* **근거:** 외부 근거 없음: 대상 사용자와 기본 언어는 제품 소유자의 결정이며 외부 사실에 기대지 않는다.
* **관련:** [ADR 0002](0002-locale-i18n.md)의 기본 로케일 `ko` 결정을 대체한다. 지원 로케일(ko·en), 로케일을 정하는 순서, 첫 대화형 실행에서 한 번 묻는 동작은 그대로 둔다.

## 배경 (Context)

ADR 0002는 영어 기본을 검토했지만, 국제화 이전부터 쓰던 사용자의 출력이 바뀌어 호환성이 깨진다는 이유로 한국어 기본을 택했다. 제품 소유자는 2026-09-15에 이름을 Agent Context Manager로 바꾸면서([ADR 0013](0013-rename-agent-context-manager.md)) 이전 이름으로 설치한 사용자를 고려하지 않기로 했으므로, 그 이유가 더는 성립하지 않는다. 같은 날 제품 소유자는 패키지의 기본 언어를 영어로 정했다. 저장소 문서는 지금처럼 한국어를 기본으로 두고 `README.en.md`를 함께 둔다.

## 검토한 대안 (Options)

1. **한국어 기본 유지:** 바꿀 것이 없다. 대신 한국어를 쓰지 않는 사용자는 비대화형 실행과 CI에서 매번 언어를 지정해야 한다.
2. **운영체제 언어 설정(`LANG` 등)을 따른다:** 사용자마다 알맞은 언어가 나올 수 있다. 대신 CI와 서버의 기본 언어 설정이 제각각이라 같은 명령의 출력과 생성 지침이 실행 환경에 따라 달라진다.
3. **영어 기본:** 로케일을 지정하지 않으면 영어로 동작하고, 한국어는 명시적으로 고른다.

## 결정 (Decision)

3을 택한다.

- `DEFAULT_LOCALE`은 `en`이다. 지원 로케일 목록과 오류 문구의 순서도 `en`, `ko`로 둔다.
- 첫 대화형 실행의 언어 선택 화면은 English를 먼저 보여 준다.
- 새 프로필의 기본 템플릿은 영어 `templates/profile/AGENTS.md`이고 한국어는 `templates/profile/AGENTS.ko.md`다.
- 한국어는 `--lang ko`, `AGCTX_LANG=ko`, `agctx config lang ko`로 고른다.

## 결과 및 영향 (Consequences)

- **호환성 파괴:** 로케일을 지정하지 않은 비대화형 실행의 출력과 새 프로필·프로젝트의 지침이 영어로 나온다.
- 한국어 출력을 단언하는 평가(`evals/profile.test.ts`, `evals/conflict-resolve.test.ts`)는 파일 맨 앞에서 `AGCTX_LANG=ko`로 로케일을 고정한다. `evals/i18n.test.ts`의 기본 로케일 평가는 영어 기대값으로, 한국어 생성 평가는 `AGCTX_LANG=ko`로 바꾼다. 요구가 바뀌어 고친 평가다.
- CLI 오류 문구는 아직 로케일과 관계없이 영어다. 오류 문구에 다음에 실행할 명령을 붙이는 개편(M1)에서 메시지 카탈로그로 옮기고 한국어 번역을 채운다.
