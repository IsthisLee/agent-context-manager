# 0027. 출력 스타일은 프로필이 담지 않는다

* **상태:** 채택됨 (Accepted)
* **일자:** 2026-09-18
* **결정자:** 제품 소유자
* **근거:** [출력 스타일을 담지 않는 근거](../references.md#출력-스타일을-담지-않는-근거)
* **관련:** [ADR 0021](0021-profile-scope-skills-mcp-subagents.md)과 [ADR 0022](0022-profile-scope-hooks.md)는 출력 스타일을 "이 결정에 넣지 않는다"며 보류했다. 이 ADR이 그 보류를 지원하지 않는 것으로 확정한다. 프로필이 담는 대상은 규칙·스킬·MCP·subagents·hooks 다섯 가지로 그대로다.

## 배경 (Context)

- 팀이 같은 응답 형식을 맞추고 싶다는 요구가 있었다. Claude Code의 출력 스타일은 역할·어조·응답 형식을 매 응답에 적용한다.
- 파일 자체는 배포할 수 있다. 프로젝트 범위 스타일은 `.claude/output-styles/*.md`에 두고 커밋해 공유하며, frontmatter와 본문으로 된 마크다운이라 agctx의 관리 블록·해시 방식이 그대로 얹힌다.
- 그런데 세 가지가 걸린다. 어떤 스타일을 쓸지는 `outputStyle` 설정이고 `/config`가 이를 개인 설정 파일에 쓴다. `keep-coding-instructions`의 기본값은 `false`라 커스텀 스타일을 켜면 Claude Code의 내장 소프트웨어 엔지니어링 지침이 빠진다. 그리고 이 기능은 Claude Code에만 있다.

## 검토한 대안 (Options)

| 대안 | 판단 |
| --- | --- |
| 스타일 파일과 선택을 모두 프로필이 관리한다 | 선택은 개인 설정 파일(`.claude/settings.local.json`)에 저장된다. 이 파일을 팀 프로필이 덮어쓰면 개인 설정을 침범한다 |
| 파일만 배포하고 켜는 것은 안내한다 | 배포해도 아무도 켜지 않으면 효과가 없고, 켠 사람은 내장 엔지니어링 지침을 잃을 수 있다 |
| 지원하지 않는다 | **채택.** 공유되지 않는 선택, 우리 지침과 충돌하는 기본값, 한 에이전트 전용이라는 세 가지가 겹친다 |

## 결정 (Decision)

- 프로필은 출력 스타일 파일을 관리하지 않는다. `profile apply`·`sync`가 `.claude/output-styles/`에 쓰지 않고, `explain`·`verify`도 그 폴더를 보지 않는다.
- 이유는 세 가지다.
  1. **선택이 공유되지 않는다.** 스타일 파일을 커밋해도 어떤 스타일을 쓸지는 개인 설정에 저장된다. 팀 프로필이 강제할 수 없고, 강제하려면 개인 설정 파일을 덮어써야 한다. agctx는 사람이 쓴 파일을 덮어쓰지 않는다.
  2. **우리 지침과 충돌한다.** `keep-coding-instructions`를 켜지 않은 커스텀 스타일은 Claude Code의 내장 엔지니어링 지침(변경 범위를 잡는 방법, 작업을 검증하는 방법)을 뺀다. 우리가 배포하는 검증·범위·변경 검토 지침과 정면으로 부딪힌다.
  3. **한 에이전트 전용이다.** Codex의 설정은 모델·추론·샌드박스·승인·프로필·MCP를 다루고 대응하는 개념이 없다. Antigravity 규칙 문서에도 없다. 프로필은 여러 에이전트에 같은 내용을 전달하는 도구이므로, 한 에이전트에만 있는 기능은 프로필의 대상으로 맞지 않다.
- 응답의 언어와 어조를 팀에서 맞추고 싶으면 지침으로 쓴다. `profile setup --language`가 프로필 로케일에 맞는 문장을 넣는다([ADR 0026](0026-guidance-items-and-evidence-tiers.md)). 그보다 자세한 형식 규칙은 프로필 `AGENTS.md`의 guidance 블록 밖에 직접 쓴다.

## 결과 및 영향 (Consequences)

- 사용자가 출력 스타일을 쓰는 것은 막지 않는다. agctx가 그 파일을 만들거나 고치거나 검사하지 않을 뿐이다.
- 다른 에이전트에 같은 개념이 생기고 선택까지 공유할 수 있게 되면 이 결정을 다시 볼 수 있다. 그때는 새 ADR로 바꾼다.
- 제품 방향의 범위와 경계에 이 결정을 반영한다.
