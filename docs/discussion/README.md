# Discussion

이 디렉터리는 아직 채택되지 않았거나 구현·검증 중인 주제별 논의를 관리한다. 논의는 유형별 하위 디렉터리에 기록하며, 현재 사실이 된 결정은 ADR을 거쳐 `docs/architecture/` 또는 해당 운영 문서로 옮긴다.

## 논의 영역

| 영역 | 위치 | 다루는 내용 |
|---|---|---|
| 아키텍처 | [architecture/](architecture/) | ProjectProfile, 역할 정책, 검증·동기화 계약 |

제품 방향·운영·보안 등 새로운 논의가 필요해지면 이 디렉터리 아래에 해당 주제 폴더와 `README.md`를 추가한다. 각 주제 문서는 `**상태:**`를 기록하고, 상태 관리 규칙은 [아키텍처 논의의 구현 문서화 계약](architecture/implementation-contracts.md)을 따른다.
