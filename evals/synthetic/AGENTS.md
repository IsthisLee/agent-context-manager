# Agent Guidelines for synthetic-demo

이 저장소는 **결정론적 TDD 원칙**에 따라 AI 에이전트(Codex, Claude Code, Antigravity)와 협업하여 개발된다.

---

## 1. 핵심 행동 규약 (필수 준수)

1. **말보다 기계의 검증 증거가 우선이다.**
   - 코드 수정 후에는 반드시 검증 명령을 실행하여 통과 여부를 확인하라.
   - 검증 명령: `npm run check`
   - 테스트를 실행하지 않고 "완료했습니다"라고 보고하는 것은 금지된다. 테스트 0개는 실패다.
2. **최소 변경 원칙 (Minimal Diff).**
   - 요청받은 기능/버그와 무관한 파일의 리팩터링이나 전역 포맷팅 변경을 하지 마라.
3. **비밀값 보호.**
   - `.env`, 비밀 키, 개인정보를 화면에 출력하거나 커밋하지 마라.
4. **Git 워크플로.**
   - 사용자 승인 없는 `git push --force` 및 파괴적 명령 금지.

---

## 2. 프로젝트 실행 및 검사 명령

* **환경 및 지침 진단:** `node tools/agentic/doctor.mjs`
* **자가 검증 (정적분석 + 테스트):** `npm run check`
* **개발 서버 시작:** `npm start`

---

## 3. 규칙 개선 및 승격 가이드 (Rule Promotion)

이 프로젝트에서 유용한 범용 패턴을 발견한 경우:
* 서브에이전트를 띄우거나 `agentic` Core 저장소에 직접 범용 규칙을 추가할 수 있다.
* 단, 이 프로젝트의 도메인 명칭, 회사 기밀, 내부 데이터는 100% 마스킹하여 순수 기술 패턴으로만 작성해야 한다.
